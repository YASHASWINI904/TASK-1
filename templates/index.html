About NestEstimate

NestEstimate is an educational house-price estimation project. Its linear regression model is implemented with NumPy using batch gradient descent; scikit-learn is not used for training or prediction.

PythonFlaskHTML / CSS / JavaScriptNumPyLinear Regression
ⓘ For educational demonstration only. The generated dataset is synthetic and is not a source of verified market valuations.
